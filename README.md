# EduBuddy AI

## Problem

Many students struggle to understand concepts and rely on memorization.

## Solution

EduBuddy AI is an educational assistant that provides explanations, quizzes and personalized study recommendations.

## Features

- AI Question Answering
- Quiz Generation
- Study Planner
- Progress Tracking

## Technologies

- HTML
- CSS
- JavaScript
- OpenAI API

## Future Improvements

- LMS Integration
- Teacher Dashboard
- Analytics
