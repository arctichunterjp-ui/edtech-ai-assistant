# EduPulse JP – Japanese JLPT MCQ Practice

Open-source EdTech tool for learning Japanese (JLPT **N5 + N4**) with multiple-choice drills, timed mock tests and an **AI usage coach** that explains how to use each word. Built for Hacktoberfest 2026 (Ulaanbaatar x erxes Hub).

## Features
- **Vocabulary practice** – endless MCQs (word → meaning, word → reading, meaning → word) with score and streak
- **Mock test** – 20 mixed questions, 10-minute timer, mistake review, 60% practice pass mark
- **✨ AI usage coach** – after answering, ask the AI when and how a native speaker uses the word, with 2 level-appropriate example sentences and a common-mistake tip
- **Data-driven** – all words live in `data/vocab.js`, generated by `scripts/build_vocab.py`

## Run it
No build step. Open `index.html` in a browser, or enable **GitHub Pages** (Settings → Pages → `main` / root).

## AI setup
Click **⚙ AI settings**:
- **Gemma 4 via Gemini API** (default model `gemma-4-26b-a4b-it`): paste a free key from Google AI Studio.
- **Ollama (local)**: run an open-weight model locally, set `OLLAMA_ORIGINS=*`, and enter the model name.

Keys stay in your browser's localStorage. Never commit a key. AI output can be wrong; verify with your textbook.

## Update the vocabulary
1. N5: extracted from the N5 PDF text layer (`python3 scripts/build_vocab.py jlpt-n5-vocabulary.pdf`, needs `pdftotext`).
2. N4: add rows to `data/n4.tsv` (`word<TAB>reading<TAB>meaning`), then re-run the script. The N4 source PDF is a scan, so it is being transcribed in batches.
